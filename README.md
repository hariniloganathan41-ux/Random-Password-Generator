# 🔐 Random Password Generator

## About the Project
A simple application that generates random
passwords to help users create stronger passwords.

## Technologies Used
- Java
- Java Swing
- HTML
- CSS
- JavaScript

## Features
- Generate random passwords
- Adjust password length
- Include uppercase and lowercase letters
- Include numbers and symbols
- Copy password to clipboard
- Check password strength

## Project Structure
- Java-Version
- Web-Version

## How to Run
Open PasswordGeneratorApp.java in a Java IDE
and run the application.
